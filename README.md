# Basic Calculator
A simple and responsive calculator built using HTML, CSS, and JavaScript. This project performs basic arithmetic operations and provides a clean user-friendly interface with real-time calculation display.
## Features
* Addition, Subtraction, Multiplication, and Division
* Percentage and Decimal Support
* Clear Screen Functionality
* Delete Last Character
* Responsive Design
* Real-Time Display Updates
* Keyboard Support
* Modern UI with Hover Effects
## Technologies Used
* HTML5
* CSS3
* JavaScript (ES6)
## Project Preview
The calculator includes:
* Display Screen
* Numeric Buttons
* Arithmetic Operators
* Clear & Delete Buttons
* Equal Button for Result
## Functionalities
### Arithmetic Operations
* Addition (+)
* Subtraction (-)
* Multiplication (×)
* Division (÷)
### Additional Features
* Decimal calculations
* Percentage calculations
* Keyboard input support
* Error handling for invalid expressions
## ⌨️ Keyboard Support
| Key       | Function              |
| --------- | --------------------- |
| 0-9       | Numbers               |
| + - * /   | Operators             |
| Enter     | Calculate Result      |
| Backspace | Delete Last Character |
| Escape    | Clear Screen          |
